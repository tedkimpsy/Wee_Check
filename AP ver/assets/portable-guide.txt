Wee Check AP 포터블 사용 안내

1. ZIP 파일을 원하는 폴더에 모두 압축 해제하세요.
2. WeeCheck-Start.vbs를 더블클릭하면 관리자 화면이 열립니다.
3. 최초 실행 또는 폴더 이동 후에는 학생 접속을 위한 방화벽 설명과 Windows 관리자 권한 확인이 나타날 수 있습니다.
4. 사용이 끝나면 WeeCheck-Stop.vbs를 더블클릭하세요. 브라우저만 닫으면 서버가 계속 실행됩니다.

포터블판은 설치 마법사, 설치된 앱 등록, 시작프로그램 등록 없이 실행됩니다. Windows를 다시 시작하면 직접 실행해야 합니다. ZIP 안에서 바로 실행하지 말고 전체 압축을 먼저 해제하세요. 함께 들어 있는 폴더와 파일을 따로 옮기지 마세요.

학생 정보는 이 PC의 %LOCALAPPDATA%\WeeCheckAP에 암호화 저장됩니다. USB로 프로그램을 옮겨도 학생 데이터가 함께 이동하지 않습니다. 설치판과 포터블판은 같은 Windows 계정의 동일한 데이터를 사용하므로 동시에 실행하지 마세요.

포터블을 지우려면 종료 후 압축 해제한 폴더를 삭제하세요. 전용 방화벽 규칙도 정리하려면 종료 후 scripts\remove-windows-firewall.ps1을 관리자 권한으로 실행하거나 전산 담당자에게 요청하세요.
