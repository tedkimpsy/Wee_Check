Wee Check AP 네트워크 설정 안내

Wee Check AP는 같은 학교 Wi-Fi에 연결된 학생용 태블릿과 휴대폰이 관리자 PC의 학생 화면에 접속할 수 있도록 Windows 방화벽 규칙을 설정합니다.

• 허용 프로그램: Wee Check AP에 포함된 전용 실행 환경
• 허용 포트: TCP 4174
• 허용 범위: 현재 PC와 같은 로컬 서브넷
• 관리자 화면: 이 PC에서만 접속 가능
• 학생 데이터: 이 PC의 암호화된 로컬 데이터베이스에만 저장
• 외부 터널 및 클라우드 저장: 사용하지 않음

설치 과정에서 Windows 관리자 권한 확인이 표시되는 것은 위 방화벽 규칙을 안전하게 추가하기 위해서입니다. 설치를 제거하면 Wee Check AP 전용 방화벽 규칙도 함께 제거됩니다.

방화벽 규칙만으로 포트가 열리지는 않습니다. 프로그램을 종료하면 학생 서버의 포트 수신도 함께 종료되며, 다른 프로그램은 이 규칙을 사용할 수 없습니다.
