# Wee Check

학생이 Wee클래스에 들어와 휴식하거나 놀고 갈 때 사용하는 출입 확인 웹 앱입니다. 들어오기는 `학년 → 반 → 이름` 순서로 선택하고, 나가기는 현재 들어와 있는 학생 목록에서 이름을 바로 선택합니다. 얼굴 정보, QR, NFC는 사용하지 않습니다. 학생 화면은 태블릿 가로 화면의 전체 너비와 높이를 사용하며 긴 명단은 스크롤할 수 있습니다.

메인 화면의 **상담 신청하기**는 학년·반·이름을 선택하고 신청 확인 버튼을 누르면 접수합니다. 입장 기록과 분리해 로컬 서버에 암호화 저장하며, 관리자 **상담 신청 확인**에서 확인 완료로 표시합니다. 자유 서술 상담 내용은 수집하지 않으며 안전 확인 답변만 저장합니다.

상담 신청에는 보호자 전화번호 필수 입력과 세 가지 안전 확인 질문이 포함됩니다. 초등학교 1·2학년에게만 잘 모르겠어요 버튼을 표시하고, 선택 시 보호자 연락처 확인 필요로 접수합니다. 다른 학년과 중·고등학교는 보호자 연락처를 입력해야 합니다. 현재 도움이 필요하다는 응답은 즉시 대면 확인, 자해 생각·안전 우려 또는 직접 이야기 요청은 우선 확인으로 표시합니다. 표준화된 임상 검사나 진단 도구가 아니며 일반 접수도 안전을 보장하지 않습니다. 담당자가 직접 확인하고 학교 위기 대응 절차에 따라 지원해야 합니다. 긴급·우선 확인 신청 후에는 자동 복귀를 중단하고 가까운 어른에게 직접 도움을 요청하라는 안내를 유지합니다. 미확인 신청을 다시 제출하면 연락처와 안전 응답을 갱신합니다.

연락처와 안전 답변은 민감정보입니다. 관리자 인증과 로컬 암호화 저장을 적용했으며, 안전 응답 뒤에는 반드시 사람이 직접 확인해야 합니다. 이 원칙은 [NIMH 안내](https://www.nimh.nih.gov/research/research-conducted-at-nimh/asq-toolkit-materials)를 참고했습니다. 본 앱 질문은 ASQ가 아닙니다.

## 로컬 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
npm run dev
```

터미널에 표시되는 주소(기본값 `http://localhost:5173`)를 브라우저에서 엽니다.

## 배포용 빌드

```bash
npm run build
npm run preview
```

## 로컬 서버 운영

실사용 모드는 관리자 Windows PC에서 로컬 서버를 실행합니다. 관리자 화면은 `http://127.0.0.1:4173/admin`에서만 열리고, 학생 화면은 별도 포트 `4174`를 Cloudflare Tunnel에 연결합니다.

```bash
npm install
npm run build
npm start
```

최초 관리자 비밀번호는 `0000`입니다. 로그인 후 관리자 화면의 경고 배너에서 8자 이상의 새 비밀번호로 바꾸는 것을 권장합니다. `cloudflared`가 PATH에 설치되어 있어야 **학생 접속 시작** 버튼으로 일일 QR을 만들 수 있습니다. 개발·점검 시에는 `WEE_CHECK_NO_TUNNEL=1`을 지정하면 로컬 학생 주소를 사용합니다.

```powershell
.\scripts\install-cloudflared.ps1
```

데이터베이스와 암호화 백업은 `%LOCALAPPDATA%\WeeCheck`에 저장됩니다. 이름·연락처·상담 답변은 AES-256-GCM으로 암호화되고 마스터 키는 Windows DPAPI로 보호됩니다. 서버 모드에서는 기존 브라우저 `localStorage` 기록을 가져오지 않습니다.

Windows 로그인 시 자동 시작을 등록하려면 관리자 PowerShell에서 다음 스크립트를 실행합니다.

```powershell
.\scripts\install-windows-autostart.ps1
```

관리자 API는 localhost에만 바인딩되며 학생용 공개 포트에는 등록되지 않습니다. 학생 QR은 매일 새로 생성하고 자정 또는 관리자의 접속 종료 시 폐기됩니다.

최초 학생 명단은 `src/defaultRoster.ts`의 예시 데이터로 동작합니다. 관리자에서 학교급을 선택하면 초등학교는 1-6학년, 중학교·고등학교는 1-3학년 명단을 표시합니다. 학교급을 바꿔도 기존 명단은 보관합니다.

관리자의 **학교 설정 · 학생 명렬표**에서 엑셀의 학년·반·이름 세 열을 복사해 붙여넣고, **미리보기**를 확인한 뒤 **이 명렬표로 전체 교체**를 눌러 업데이트합니다. 설정과 명렬표는 로컬 서버에 저장되고 학생은 UUID로 연결되어 기존 기록이 유지됩니다.

## 관리자 화면

관리자는 현황·운영 상태·학교 및 명렬표 요약을 카드형 대시보드에서 확인합니다. 명렬표 편집, 전체 학생 검색, 개방 시간 설정은 각각 모달에서 처리합니다. 모달은 닫기 버튼 또는 Esc로 닫을 수 있습니다.

수동 개방·닫힘은 토글 스위치로 전환합니다. 회의중·상담중·수업중·출장중·식사중·부재중을 선택하면 학생 화면에 해당 상태의 친절한 안내와 SVG 아이콘을 표시하고 출입 버튼을 숨깁니다. 모든 특별 상태는 시간표보다 우선합니다. 수동 방식에서는 스위치를 켜서 다시 개방하며 시간표 방식에서는 시간표 복귀 버튼을 사용합니다.

**개방 시간 → 설정**에서 수동 또는 요일별 시간표 방식을 선택합니다. 시간표 운영 중에는 임시 휴무와 회의·상담 등의 상태가 시간표보다 우선하며 **시간표대로 다시 운영**으로 해제합니다. 설정은 로컬 서버에 저장됩니다.

상단의 **관리자** 버튼으로 출입 현황을 확인합니다. 선택한 날짜의 재실 학생, 중복을 제외한 들어오기·나가기 인원, 학년별 방문 현황을 표시합니다. 학생 목록은 이름, 학년, 재실·나가기 상태로 검색할 수 있습니다.

관리자의 **운영 모드**에서 개방·회의중·상담중을 선택합니다. 회의중·상담중에는 메인 화면 전체에 상태 안내와 SVG 그림을 표시하며, 입장·나가기 버튼 및 통계를 숨기고 모든 출입 확인을 중단합니다. 종료 후 개방으로 직접 변경합니다. 모드는 새로고침 후에도 유지되며 같은 브라우저의 다른 탭에도 반영됩니다. 진행 중인 출입 선택도 제한 시 처음 화면으로 돌아갑니다.

회의중·상담중 안내는 학교급 구분 없이 공통으로 친절한 문구를 사용합니다.

들어오기·나가기 기록은 관리자 PC의 로컬 암호화 데이터베이스에 저장됩니다. 날짜와 시간은 한국 시간 기준이며, 서버 트랜잭션으로 중복 입장과 당일 들어오기 기록 없는 나가기를 차단합니다.

들어오기에서는 학년·반·이름을 선택한 뒤 **오늘의 마음 날씨**를 확인합니다. 응답은 출입 기록과 함께 로컬 서버에 저장되고 관리자 대시보드에서 선택 날짜의 분포를 확인할 수 있습니다.

마음 날씨는 학생이 현재 마음을 편하게 표현하도록 돕는 기능이며 표준화된 심리검사, 위기 선별 또는 진단 도구가 아닙니다. 이름과 연결된 기록은 학년도 마감 시 암호화 백업 후 정리합니다.

관리자 API는 localhost 전용이며 학생용 공개 포트에서는 접근할 수 없습니다. 학생 접속 세션은 매일 새로 생성되고 자정에 만료됩니다.
