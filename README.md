# Wee Check AP

> 학교가 관리하는 Wi-Fi 안에서 학생 출입, 마음 날씨, 상담 신청을 관리하는 Wee클래스용 프로그램

Wee Check AP는 학교 전문상담교사를 위한 Windows 프로그램입니다. 교사가 노트북에서 프로그램을 실행하고 같은 학교 Wi-Fi에 연결된 태블릿 PC로 QR 코드를 읽어 학생용 화면을 준비합니다. 학생은 준비된 태블릿에서 출입을 기록하거나 상담을 신청합니다.

학생 이름, 출입 기록, 마음 날씨와 상담 신청은 교사용 노트북에 암호화하여 저장합니다. 인터넷상의 별도 저장소에 학생 정보를 올리지 않습니다.

![학생용 첫 화면](AP%20ver/docs/images/student-home.png)

## 어떤 일을 할 수 있나요?

- 학생이 자신의 이름을 선택해 들어오기·나가기를 기록합니다.
- 입실할 때 마음 날씨를 선택하고 상담을 신청할 수 있습니다.
- 교사는 현재 이용 학생, 대기·예약, 상담 신청과 방문 통계를 확인합니다.
- 정원과 놀이시간, 요일별 개방 시간을 설정합니다.
- 학생 명렬표를 관리하고 기록을 암호화 백업합니다.

## 내려받고 시작하기

| 배포판 | 다운로드 | 실행 방식 |
| --- | --- | --- |
| 설치판 | [설치 EXE 0.1.3](AP%20ver/release/WeeCheck-AP-Setup-0.1.3.exe) | 한 번 설치하면 현재 Windows 계정에 로그인할 때 자동 실행 |
| 포터블판 | [포터블 EXE 0.1.3](AP%20ver/release/WeeCheck-AP-Portable-0.1.3.exe) | EXE 하나를 더블클릭해 바로 실행. Windows를 다시 켜면 직접 실행 |

파일 화면에서 **Download raw file**을 눌러 내려받으세요. 64비트 Windows 10/11과 학교가 관리하는 보안 Wi-Fi가 필요합니다. 두 버전 모두 학생 기기 접속을 위한 방화벽 설정 시 관리자 권한이 필요할 수 있습니다. 포터블판은 설치와 자동 실행 등록을 하지 않습니다.

같은 노트북에서 두 버전을 동시에 사용하지 마세요. 데이터는 두 버전 모두 해당 PC에 보관하며, 포터블 파일을 USB로 옮겨도 학생 데이터가 함께 이동하지 않습니다.

1. [설치 안내](docs/manual/installation.md)를 따라 프로그램을 설치합니다.
2. [처음 실행 안내](docs/manual/first-steps.md)에 따라 로그인하고 학교와 학생 정보를 준비합니다.
3. [매일 운영 안내](docs/manual/daily-use.md)를 보며 교사가 태블릿 PC의 학생용 화면을 준비합니다.

## 개인정보 처리방침

적용 대상: 이 저장소에서 배포하는 Wee Check AP 설치판·포터블판 · 시행일: 2026년 10월 29일

**Wee Check AP는 학교 PC에서 실행되는 로컬 프로그램이며, 개발자는 프로그램 이용자의 개인정보와 학생 정보를 수집·이용하거나 외부 서버로 전송받지 않습니다.** 개발자는 학교 PC에 저장된 정보에 접근하거나 이를 열람·분석하지 않으며, 광고·마케팅 목적으로 이용하거나 제3자에게 제공하지 않습니다.

### 학교 PC 내부의 정보 처리

프로그램은 학교가 입력한 학생 명렬표, 출입 기록, 마음 날씨, 상담 신청과 보호자 연락처 등을 Wee클래스 운영을 위해 해당 PC에 저장하고 조회합니다. 따라서 **개발자의 개인정보 수집이 없다는 의미이며, 학교 안에서도 개인정보 처리가 전혀 없다는 의미는 아닙니다.** 교사가 준비한 태블릿과 PC 사이에는 기능 이용에 필요한 정보가 학교 Wi-Fi를 통해 전달됩니다.

학생 정보와 상담 내용은 `%LOCALAPPDATA%\WeeCheckAP`의 로컬 데이터베이스에 암호화하여 저장하며, 백업도 해당 PC에 보관합니다. 프로그램 삭제만으로 기록과 백업이 자동 삭제되지는 않습니다. [데이터 보관·삭제 안내](docs/manual/data-and-removal.md)를 확인하세요.

### 학교의 관리와 정보주체의 권리

정보를 입력하고 운영하는 학교는 관계 법령과 학교·교육청 지침에 따라 처리 근거, 필요한 동의·안내, 접근 권한, 보유 기간, 백업과 파기를 정해야 합니다. 이 안내는 각 학교의 개인정보 처리방침을 대신하지 않습니다. 학생·보호자의 열람·정정·삭제 등 요청은 해당 정보를 보관·운영하는 학교 담당자에게 문의해 주세요. 개발자는 학교의 기록을 보유하지 않으므로 이를 직접 조회하거나 삭제할 수 없습니다.

프로그램 문의 시 학생 명단, 상담 내용, 연락처, 데이터베이스나 백업 파일을 이메일 또는 공개 게시물로 보내지 마세요. 오류 화면을 전달할 때는 개인정보를 가려 주세요. 사용자가 별도로 보내는 문의 내용은 프로그램의 로컬 저장과 구분됩니다.

## 면책 조항

Wee Check AP는 학교 상담실의 운영을 돕는 도구이며, 의료적 진단·심리검사·위기 판정이나 전문상담교사의 판단을 대신하지 않습니다. 마음 날씨와 상담 분류만으로 학생의 안전을 판단하지 말고, 담당자가 직접 확인하고 학교의 위기 대응 절차를 적용해야 합니다.

프로그램은 제공되는 상태를 기준으로 배포되며, 오류 없는 작동, 중단 없는 이용, 특정 목적에 대한 적합성 또는 모든 환경에서의 보안을 보증하지 않습니다. 사용자는 학교의 설치·보안 지침을 확인하고, 중요한 기록을 백업하며, PC와 Wi-Fi의 접근 권한을 관리해야 합니다.

관계 법령이 허용하는 범위에서 개발자는 프로그램의 사용·사용 불가, 기기나 네트워크 장애, 사용자 설정·관리상의 문제 등으로 발생한 기록 손실, 업무 중단 또는 그 밖의 손해에 대해 책임을 제한합니다. 다만 이 조항은 법령상 배제할 수 없는 책임이나 개발자의 고의·중대한 과실에 따른 책임을 면제하지 않으며, 이용자와 정보주체의 법적 권리를 제한하지 않습니다.
