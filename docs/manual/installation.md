# 1. 설치하기

[설명서 목차](README.md) · [프로그램 소개](../../README.md)

## 사용 환경 확인

사용 전에 다음 조건을 확인합니다.

- 교사용 노트북은 64비트 Windows 10 또는 Windows 11을 사용해야 합니다.
- 교사용 노트북과 교사가 준비하는 태블릿 PC가 **같은 학교 Wi-Fi**에 연결되어야 합니다.
- 학교가 관리하는 암호화된 Wi-Fi에서만 사용합니다. 카페·도서관 등의 공용 Wi-Fi에서는 사용하지 마세요.
- 학교 Wi-Fi가 기기끼리의 통신을 차단하도록 설정되어 있으면 학생 기기에서 접속할 수 없습니다. 이 경우 학교 전산 담당자에게 “같은 Wi-Fi에 연결된 기기 사이의 통신이 허용되어 있는지” 문의하세요.
- 처음 설치할 때 Windows 관리자 권한이 필요할 수 있습니다.

## 설치 파일 내려받기

아래 파일을 누른 뒤 GitHub 화면의 **Download raw file** 버튼을 눌러 내려받습니다.

| 선택 | 다운로드 | 권장 상황 |
| --- | --- | --- |
| 설치판 | [설치 EXE 0.1.3](../../AP%20ver/release/WeeCheck-AP-Setup-0.1.3.exe) | 매일 같은 노트북에서 사용하며 Windows 로그인 시 자동 실행하려는 경우 |
| 포터블판 | [포터블 EXE 0.1.3](../../AP%20ver/release/WeeCheck-AP-Portable-0.1.3.exe) | 설치 없이 EXE를 바로 실행하려는 경우 |

두 버전 모두 학생 접속을 위한 최초 방화벽 설정에는 관리자 권한이 필요할 수 있습니다. 포터블판도 학교 보안 정책을 따릅니다.

> [!IMPORTANT]
> 현재 설치 파일에는 유료 코드 서명이 적용되어 있지 않습니다. 따라서 Windows가 “PC 보호” 화면을 표시할 수 있습니다. 반드시 이 저장소에서 직접 내려받은 파일인지 확인하고, 학교 또는 교육청의 프로그램 설치 정책을 먼저 따르세요.

## 설치 진행

1. 내려받은 `WeeCheck-AP-Setup-0.1.3.exe`를 더블클릭합니다.
2. Windows가 확인 창을 표시하면 파일 이름과 내려받은 위치가 맞는지 확인합니다.
3. 설치 안내를 읽고 설치 위치를 확인합니다.
4. 학생 기기의 접속을 허용하기 위한 Windows 방화벽 안내가 나타납니다. 내용을 읽은 뒤 계속합니다.
5. Windows 관리자 권한 요청 창이 나타나면 게시자와 실행 내용을 확인한 뒤 **예**를 누릅니다.
6. 설치가 끝나면 바탕화면과 시작 메뉴에 **Wee Check AP** 바로가기가 만들어집니다.

관리자 권한 요청을 취소하거나 학교 정책 때문에 설정이 완료되지 않으면 프로그램이 자동으로 시작되지 않습니다. 바탕화면의 **Wee Check AP**를 다시 실행하면 안내와 함께 설정을 다시 시도할 수 있습니다. 계속 실패하면 학교 전산 담당자에게 설치를 요청하세요.

## 설치판 자동 실행

설치한 Windows 사용자 계정에 로그인할 때 Wee Check AP와 관리자 화면이 자동으로 시작됩니다. Windows 부팅 전이나 다른 사용자 계정에서는 실행되지 않습니다. Wi-Fi 연결 후 학생 접속 상태를 확인하세요. 자동으로 열리지 않으면 바탕화면 바로가기를 누릅니다.

자동 실행을 끄려면 Windows **설정 → 앱 → 시작 프로그램**에서 **Wee Check AP**를 끕니다. 설치판을 제거하면 시작프로그램 바로가기도 제거됩니다.

## 포터블판 시작하기

1. `WeeCheck-AP-Portable-0.1.3.exe`를 내려받아 더블클릭합니다.
2. 필요한 파일이 자동으로 준비됩니다. 처음 실행할 때는 잠시 기다립니다.
3. 최초 방화벽 안내와 권한 요청이 나타나면 내용을 확인합니다.
4. 자동으로 열린 관리자 화면에서 로그인합니다.
5. 사용을 마치면 포터블 실행 창의 **종료**를 누릅니다. 실행 창을 닫았다면 작업 표시줄 알림 영역의 Wee Check 아이콘에서 **종료**를 선택합니다.

별도로 압축을 풀거나 설치할 필요가 없습니다. Windows를 다시 시작하면 포터블 EXE를 직접 실행해야 합니다. 브라우저나 포터블 실행 창을 닫기만 하면 서버는 계속 실행되므로 반드시 **종료**를 사용하세요. 파일 실행이 학교 정책으로 제한되면 전산 담당자에게 문의하세요.

포터블판은 설치 마법사, 설치된 앱 목록 등록, 시작프로그램 등록을 하지 않습니다. 실행에 필요한 파일만 `%LOCALAPPDATA%\WeeCheckAPPortableCache`에 자동으로 준비합니다. 학생 정보는 USB가 아니라 해당 PC에 저장됩니다. 설치판과 포터블판은 동일한 PC 데이터를 사용하므로 하나만 실행하세요.
