# 4. 학생에게 안내하기

[설명서 목차](README.md) · [프로그램 소개](../../README.md)

![학생용 첫 화면](../../AP%20ver/docs/images/student-home.png)

교사가 미리 접속해 둔 태블릿 PC에서 이용합니다. 학생이 QR 코드를 읽거나 자신의 휴대전화로 접속할 필요는 없습니다. 준비된 학생용 첫 화면에서 **들어오기**, **나가기**, **상담 신청하기** 중 필요한 항목을 선택합니다.

## 들어오기와 나가기

1. 첫 화면에서 **들어오기**를 누릅니다.
2. 자신의 학년, 학급, 이름을 차례로 선택합니다.
3. 오늘의 마음 날씨를 선택하고 화면의 완료 안내를 확인합니다.
4. 이용을 마치면 첫 화면의 **나가기**에서 자신의 정보를 선택해 퇴실합니다.

정원이 모두 찬 경우 학생은 대기를 신청할 수 있습니다. 자리가 생기면 첫 번째 대기자에게 5분 동안 유효한 입실 기회가 주어집니다.

## 상담 신청

첫 화면에서 **상담 신청하기**를 선택하고 자신의 학년·학급·이름을 고른 뒤 안내에 따라 고민 주제, 연락처, 안전 확인 질문에 답합니다. 신청 후에는 담당 교사가 [상담 관리](menus/counseling.md)에서 확인합니다.
