# 2. 처음 실행하고 준비하기

[설명서 목차](README.md) · [프로그램 소개](../../README.md)

![로그인 후 보이는 대시보드와 왼쪽 관리자 메뉴](../images/guide/overview.jpg)

왼쪽에 메뉴 이름이 보이지 않으면 화면 왼쪽 위의 **사이드바 펼치기** 버튼을 누르세요. 아래 화면들은 처음 사용하는 상태를 기준으로 촬영했습니다. 명렬표의 이름은 프로그램에 포함된 예시입니다.

1. 설치판은 바탕화면의 **Wee Check AP**를, 포터블판은 내려받은 포터블 EXE를 더블클릭합니다.
2. 잠시 기다리면 웹브라우저에 관리자 화면이 열립니다.
3. 초기 비밀번호 `0000`을 입력합니다.
4. 로그인 직후 화면 위쪽의 비밀번호 변경 안내를 누릅니다.
5. 다른 사람이 추측하기 어려운 8자 이상의 새 비밀번호로 변경합니다.

관리자 화면은 프로그램을 실행한 교사용 노트북에서만 열립니다. 이미 실행 중일 때 바로가기를 다시 누르면 프로그램을 중복 실행하지 않고 기존 관리자 화면을 엽니다.

## 첫 운영 전 준비 순서

1. [학교 정보와 학생 명렬표](menus/students.md)를 등록합니다.
2. [운영 상태와 학생 접속](menus/operations.md)에서 개방 상태와 QR을 확인합니다.
3. [정원과 놀이시간](menus/operations.md#정원대기놀이시간)을 학교 운영 방식에 맞게 정합니다.
4. 학생 기기 한 대로 [학생 이용 방법](student-use.md)을 따라 접속을 확인합니다.

준비가 끝나면 [매일 운영하기](daily-use.md)를 참고하세요.
