로그인하면 처음 보이는 화면입니다. 하루 운영 상황을 한눈에 확인합니다.

## 확인 순서

1. **즉시 확인이 필요한 상담**에서 새 신청과 우선순위를 확인합니다. **전체 보기**로 상담 관리에 이동합니다.
2. **현재 이용 학생**에서 이용 중인 학생과 시간을 확인합니다.
3. 가운데 숫자로 현재 인원, 대기, 입실 예약과 오늘 방문을 확인합니다.
4. 아래 마음 날씨와 학년별 방문으로 당일 이용 흐름을 살펴봅니다.
5. 다른 날짜를 보려면 오른쪽 위 날짜를 선택합니다.
