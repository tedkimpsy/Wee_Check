# 3. 매일 운영하기

[설명서 목차](README.md) · [프로그램 소개](../../README.md)

### 운영 시작

1. 교사용 노트북을 학교 Wi-Fi에 연결합니다.
2. 설치판은 Windows 로그인 후 자동으로 열리는 관리자 화면을 확인합니다. 포터블판은 내려받은 포터블 EXE를 더블클릭합니다.
3. 관리자 화면에 로그인합니다.
4. **운영 · 학생 접속**에서 운영 상태와 시간표를 확인합니다.
5. 교사가 태블릿 PC로 현재 QR 코드를 읽어 학생용 화면을 엽니다. 학생이 바로 사용할 수 있도록 화면을 준비해 둡니다.

### 운영 중 확인

![현재 이용 학생과 상담 알림을 함께 확인하는 대시보드](../images/guide/overview.jpg)

왼쪽 위에서 새 상담을, 오른쪽 위에서 현재 이용 학생을 먼저 확인합니다. 더 자세히 살펴보려면 해당 영역의 **전체 보기**를 누릅니다.

관리자 대시보드에서 다음 내용을 확인할 수 있습니다.

- 현재 이용 중인 학생과 이용 시간
- 정원, 대기 순서와 입실 예약
- 오늘의 마음 날씨 현황
- 새 상담 신청과 긴급 확인이 필요한 신청
- 최대 이용시간을 넘긴 학생

### 운영 종료

1. 필요한 경우 관리자 화면에서 운영 상태를 **닫힘**으로 바꿉니다.
2. 설치판은 Windows 시작 메뉴에서 **Wee Check AP 종료**를 누릅니다. 포터블판은 실행 창 또는 작업 표시줄 알림 영역의 Wee Check 아이콘에서 **종료**를 누릅니다.
3. 종료 안내가 나타나면 확인합니다.

브라우저 창만 닫으면 화면만 사라지고 프로그램은 계속 실행될 수 있습니다. 각 버전의 종료 기능을 사용하세요. 정상적으로 종료하면 학생용 접속도 함께 끝납니다.

## 잠시 자리를 비울 때

[운영 · 학생 접속](menus/operations.md)에서 상담 중·회의 중·부재 중 등 현재 상황을 선택합니다. 운영을 재개할 때는 개방으로 바꿉니다.

## 마치기 전에

중요한 명렬표 변경이 있었다면 [백업 · 학년도](menus/system.md)에서 백업을 만든 뒤 종료합니다.
